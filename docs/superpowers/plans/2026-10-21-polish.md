> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shadows that are never cut, tidier picker controls, a green end orb, a simpler widget with battery and a profile picker, and the guide sheet's Home Assistant text brought up to date.

**Architecture:**
- The shadow fixes go into the shared helpers (`Ui.kt` sheets, `SpotPicker` windows), so every screen built on them inherits them.
- The widget's state logic becomes a pure `WidgetState` function, unit-tested on the JVM. `BandWidget` only maps it to `RemoteViews`.
- The profile picker is a small translucent `Screen` that reuses `choose()`.

**Tech Stack:** Kotlin (plain Android SDK, no AndroidX), RemoteViews, JUnit 4, ffmpeg/ImageMagick for the band still, emulator ag36 (visible floating pinned window).

Spec: `docs/superpowers/specs/2026-10-21-polish-design.md`. Branch `groundwork`. **No tag, no merge, no push.**

```kotlin
package dev.kb896.airgestures

/**
 * What the widget shows, from the service's state: the chip (OFF, DISCONNECTED, or ON with
 * the band's charge after a dot) and the colour of the chip and of each button: brand green
 * on, coral off, grey while the band is being looked for.
 */
data class WidgetState(val chip: String, val chipTone: Tone, val power: Tone, val hand: Tone) {
    enum class Tone { LIVE, STOP, GREY }

    companion object {
        fun of(running: Boolean, connected: Boolean, paused: Boolean, battery: Int?): WidgetState {
            if (!running) return WidgetState("OFF", Tone.STOP, Tone.STOP, Tone.STOP)
            val hand = if (paused) Tone.STOP else Tone.LIVE
            if (!connected) return WidgetState("DISCONNECTED", Tone.GREY, Tone.LIVE, hand)
            val chip = listOfNotNull("ON", battery?.let { "$it %" }).joinToString(" · ")
            return WidgetState(chip, Tone.LIVE, Tone.LIVE, hand)
        }
    }
}
```
