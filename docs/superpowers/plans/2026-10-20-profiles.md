# Profiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Several named profiles (gestures + dial), per-app profiles that lock while their app is in
front, and index/middle triple taps that move to the next/previous profile.

**Spec:** `docs/superpowers/specs/2026-10-20-profiles-design.md` · **Branch:** `groundwork`

**Checks:** `cd rust && cargo test --workspace`; `./gradlew assembleDebug lintDebug testDebugUnitTest`
(lint errors 0).

### Task 1: bridge triple taps (TDD, Rust)
- `config.rs`: `BandConfig.profile_triples: bool` (default false); `Config::apply_mapping` reads
  `triples=profiles` (any other value or absent → false). Config test.
- `controller.rs` tests (new `mod tests`): helper `tap(finger, action, t)` building a
  `GestureMessage`; `Event::Connected` at t=0, gestures from t=2. Cases: index tap ×3 (0.2 s
  apart, with the band's doubletap after the 2nd and 3rd) → exactly `[Run("profile.next")]`;
  middle → `profile.previous`; without `triples=profiles` → no profile command; with triples, a
  lone index tap with `index_double=` runs its action once at `fire_held_tap(t + 0.4)`.
- Implement: `triple_use(tap) -> Option<Triple>` (`Toggle` | `Profile(&'static str)`),
  `toggle_finger` beside `toggle_taps` (cleared when the finger changes), singles held when their
  finger has a triple use, `profile_by_tap(command)` (nothing while `!enabled || !live`).

### Task 2: `ProfileList` (TDD, Kotlin, pure)
- `Profile(id, name, map: Map<String,String>, dial: String)`; `ProfileList(profiles, picked, apps)`
  with `toJson`/`fromJson` (org.json is Android — so the pure class takes/returns plain
  structures; JSON lives in `Profiles.kt`), `migrated(oldMap, oldDial)`, `active(foreground)`,
  `locked(foreground)`, `step(+1/-1)`, `added(defaults)`, `renamed`, `deleted`, `assigned(pkg, id)`,
  `unassigned(pkg)`.

### Task 3: store + Prefs wiring
- `Profiles.kt`: load/save JSON in the `air-gestures` prefs, migration on first load, the
  foreground package (in memory), `speak` flag.
- `Prefs.actionId/action/dial` → active profile; `setAction(gesture, id, profile = active)`,
  `setDial(profile, dial)`; `mapping()` adds `;triples=profiles` when 2+ profiles.
- `BandService.setAction/setDial` take the profile id; static helpers too.

### Task 4: switching + feedback
- `TouchService`: `typeWindowStateChanged` in `touch_service.xml`; `onAccessibilityEvent` → filter
  (ours, systemui, current IME, no launcher entry) → `BandService.foreground(pkg)`.
- `BandService.foreground(pkg)` / `profileStep(dir)`: update, re-send mapping, `announce(name)`:
  Toast "Profile: <name>", notification text, `state.profile`, optional speech via `Actions.speak`.
- `Actions.run`: `profile.next` / `profile.previous` → `BandService` (ignored when locked).

### Task 5: screens
- `GesturesActivity` → list (profiles, New profile, During calls, speak switch).
- `ProfileActivity`: gestures + dial for one profile, Rename, Delete, Apps (add/remove).
- Home status card: Profile. Setup: Screen gestures step also when any app has a profile.
- Manifest: `ProfileActivity`. Changelog. Accessibility description.

### Task 6: verify (emulators 33/36, phone with band).
